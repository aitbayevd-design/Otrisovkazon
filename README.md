# Зона доставки ресторана

Страница строит рекомендуемую зону доставки по координатам ресторана: кольца по 0,5 км, цвет по среднему времени курьеров соседних ресторанов, вырезы под другие филиалы бренда, стоп-линии и районы без заказов. Результат выгружается в CSV, GeoJSON или списком ID ячеек H3 (разрешение 9).

## Файлы
- `index.html` — сама страница.
- `zones.js` — логика расчёта.
- `data.js` — снимок данных по городам (Алматы, Астана, Костанай). Его и нужно обновлять.

## Как выложить на GitHub Pages
1. Создайте репозиторий (или папку в существующем, например `zones/`).
2. Загрузите туда все три файла.
3. Settings → Pages → Deploy from a branch → ветка `main`, папка `/root`.
4. Через минуту страница откроется по ссылке вида `https://<аккаунт>.github.io/<репозиторий>/`.

Ссылку с уже построенной зоной можно отправить коллеге: координаты, бренд и параметры сохраняются в адресе страницы.

## Как обновлять данные
Раз в неделю или месяц попросите Claude: «обнови снимок данных для дашборда зон». Он выгрузит свежие данные из Cortex и отдаст новый `data.js`. Замените файл в репозитории, остальное не трогайте.

## Как добавить город или стоп-линию
Тоже через Claude: назовите город (по нему нужны хабы в Cortex) или опишите стоп-линию («выше аль-Фараби», «за мостом через Тобол»). Стоп-линии хранятся в `data.js` у каждого города в поле `barriers`.
